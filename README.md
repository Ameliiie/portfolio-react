Description : 

This project is a website developed with React as part of the CEF web developer training program. The goal is to create a portfolio.


The website includes :

- Home page
- Services page
- Portfolio page
- Contact page
- Mentions Legales
- GitHub profile modal
- Responsive design for mobile, tablet and desktop

Technologies used : 

- React and React router
- Boostrap and Boostraps icons 
- Git and GitHub 

Prerequisites used : 

- Node.js , npm 

launch instruction : 
In Node.js : Create folder and launch of the project 
- npx create-react-app nom-du-projet
- cd nom-du-projet
- code . ( Open Visual Studio)
- npm start
